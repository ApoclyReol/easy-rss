# RSS Reader

一个本地运行的 RSS 文献初筛工具。它不替代 Zotero、文件夹或正式文献管理软件，而是先把期刊 RSS 更新进来，再把条目快速分到不同篮子里，帮你尽快筛出真正值得保存的文章。

## 现在能做什么

- 管理 RSS 订阅：添加、编辑、启停、删除、批量导入、批量删除
- 启动应用后自动更新一次启用订阅
- 阅读页按篮子分拣文献：`未读 / 感兴趣 / 归档 / 已隐藏 / 已过期`
- 支持撤回最近一步阅读标记
- 布尔筛选未读文献，批量隐藏未命中结果
- 实验性 LLM 筛选未读文献
- 兴趣分析：按期刊统计总条目、未读、隐藏、感兴趣、归档、过期与感兴趣率

## 安装与启动

推荐直接使用项目自带脚本：

```bash
cd /Users/apocly/code/rss_reader
./run.sh
```

`run.sh` 会自动：

1. 创建本地 `.venv`
2. 安装 `requirements.txt`
3. 启动 Streamlit

启动后在浏览器打开终端里显示的本地地址即可。

## 推荐用法

1. 在“订阅管理”里添加或导入 RSS
2. 打开应用后等待后台自动更新一次
3. 在“筛选工具”里先用布尔筛选清掉明显不相关的未读条目
4. 在“文献阅读”里继续人工分拣：
   - `未读 -> 感兴趣`
   - `感兴趣 -> 归档`
   - 不需要的条目 -> `已隐藏`
5. 在“兴趣分析”里看不同期刊的感兴趣率和归档情况

## 篮子说明

- `未读`：刚入库、尚未处理
- `感兴趣`：值得稍后认真看
- `归档`：最终确认值得保留
- `已隐藏`：暂时或明确不想看
- `已过期`：隐藏太久，被系统自动归入过期

一篇文献任意时刻只会处于一个状态，状态主字段是 `items.item_status`。

## 自动更新与过期

- 应用每次启动时只自动更新一次，不做常驻定时更新
- 自动更新完成后会弹通知
- 隐藏文献会在每次自动更新或手动更新订阅后，按规则自动检查是否过期
- 当前默认过期阈值是 `30` 天

## LLM 筛选说明

LLM 筛选目前仍是实验功能，适合作为补充判断，不推荐作为每天的主流程。  
日常初筛优先推荐布尔筛选。

## 本地数据

- 数据库：`data/rss_reader.sqlite3`
- 本地配置：`data/settings.json`

`data/settings.json` 只保存在本地，默认不会提交到 Git。它也会保存布尔规则、自动更新摘要和本地 LLM 配置。
